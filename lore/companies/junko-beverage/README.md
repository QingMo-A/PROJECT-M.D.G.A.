# 企业简介

均克饮品集团（Junko Beverage Corporation）是旧世界规模最大的综合饮品企业之一。

公司早期以瓶装饮用水与碳酸饮料起家，随后通过收购地方饮品品牌与自建灌装网络，逐步进入茶饮、果汁、咖啡、功能饮料以及公共应急饮品供应领域。

与益特食品集团偏向食品保障和长期储存不同，均克的产品更深入普通人的日常生活。其自动售货机、冷柜、广告灯箱和品牌配送车曾广泛出现在便利店、学校、交通枢纽、办公区、体育场馆和商业中心。

在旧世界后期，均克开始参与城市应急饮水与灾害补给项目，并为部分公共避难设施提供瓶装水、补液饮料及大容量饮水包装。

——均克饮品集团品牌宣言

# 企业发展历程

## 第一阶段：瓶装饮品时代

均克最初主营瓶装水、汽水与果味饮料，并依靠区域灌装厂和密集的零售配送体系快速扩张。

主要优势：
- 成熟的瓶装与罐装生产线
- 城市级冷链配送能力
- 大规模零售终端覆盖
- 标准化自动售货机系统

---

## 第二阶段：品牌矩阵扩张

公司逐步进入功能饮料、罐装咖啡、即饮茶和运动补液市场。

这一时期形成多个长期品牌系列，包括：
- Junko Pure
- Junko Spark
- Junko Energy
- Junko Recovery
- Junko Brew
- Junko Tea

---

## 第三阶段：公共供应体系

旧世界后期，均克开始承担部分公共应急饮品供应合同。

主要业务包括：
- 城市应急瓶装水储备
- 公共避难设施饮水供应
- 救援人员补液饮品
- 医疗机构恢复型饮品供应
- 大型活动与交通枢纽饮品保障

均克并非城市供水系统运营者，但其灌装、仓储和配送能力使其成为多个地区应急饮用水体系的重要补充。

# 灾后记录

灾难发生后，均克大部分零售终端迅速停止补货，但由于其产品分布密度极高，未开封饮品长期散落于城市商业设施、自动售货机、仓库、配送车辆和避难设施中。

相较于依赖冷链的鲜食产品，瓶装水、汽水、能量饮和部分罐装咖啡在灾后早期具有较高保存价值。

已确认：
- 多个自动售货机网络在断电前仍保持库存
- 部分配送中心因无人接管而封存大量成品
- 应急饮品储备仓曾在灾难初期向多个避难点持续出库
- 部分 Junko Reserve 大容量饮水包装在灾后成为重要交换物资
